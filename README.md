# 으메메한 어류도감 체커

파이널 판타지 14 **어류도감 스크린샷**을 올리면 낚은 물고기를 읽어서, [FFX|V Fish Tracker](https://ff14fish.carbuncleplushy.com/)(Carbuncle Plushy)에 바로 넣을 수 있는 목록으로 만들어 주는 웹페이지입니다.

게임에는 낚시 기록을 내보내는 기능이 없어서, 트래커에서 수백 마리를 하나씩 체크해야 했던 불편을 덜려고 만들었습니다.

👉 **사용하기: https://cut-the-leash.github.io/ff14-fish-checker/**

## 사용 방법

1. 게임에서 어류도감을 열고, 오른쪽 위 **깔때기(필터) 아이콘을 끕니다.** 필터가 켜져 있으면 칸 위치가 달라져서 읽을 수 없습니다.
2. **페이지마다 스크린샷을 한 장씩** 찍습니다. 도감 창만 잘라도 되고 게임 전체 화면이어도 됩니다.
3. 사이트에 스크린샷을 끌어다 놓습니다. 파일 고르기나 `Ctrl + V` 붙여넣기도 됩니다. 순서는 상관없습니다.
4. 오른쪽 **가져오기용 목록**을 복사합니다.
5. Fish Tracker 오른쪽 위 톱니바퀴 → **Import Settings** → **Exported Data** 칸에 붙여넣고 **Load**를 누릅니다.

1~16페이지를 전부 올릴 필요는 없지만, 올리지 않은 페이지의 물고기는 목록에서 빠집니다.

## 주요 기능

- **페이지 자동 인식:** 아무 순서로 올려도 몇 페이지인지 알아내고, 빠진 페이지를 알려 줍니다.
- **결과 확인과 수정:** 페이지 번호를 누르면 스크린샷 위에 판독 결과가 표시됩니다. 애매한 칸은 노란색으로 표시되고, 칸을 눌러서 직접 고칠 수 있습니다.
- **범위 선택:** 트래커 전체 물고기 또는 터주만 내보낼 수 있습니다.
- **기존 체크와 합치기:** Fish Tracker의 Export Settings 내용을 붙여넣으면 기존 체크를 지우지 않고 합칩니다. Fish Tracker는 가져오기를 하면 기존 체크를 덮어쓰기 때문입니다.
- **텍스트 목록:** 낚은 물고기 이름을 한 줄에 하나씩 복사하거나 txt 파일로 저장할 수 있습니다.

## 개인정보

스크린샷은 **사용자의 브라우저 안에서만** 처리되고, 어떤 서버로도 전송되지 않습니다. 서버나 로그인, 설치가 필요 없는 정적 웹페이지입니다.

## 알아둘 점

- Fish Tracker는 시간·날씨 조건이 있는 물고기 위주로 다루기 때문에, 흔한 물고기와 **먼바다 낚시 물고기는 트래커 목록에 없습니다.** 이런 물고기는 낚았더라도 가져오기 목록에 들어가지 않고, 텍스트 목록의 "낚은 전체"에서만 볼 수 있습니다.
- 물고기 데이터는 Fish Tracker 데이터(글로벌 서버 기준)에서 가져왔습니다. 한국 서버에 아직 없는 물고기가 있으면 마지막 페이지 근처가 어긋날 수 있습니다.
- 같은 페이지를 여러 장 올리면 마지막에 올린 사진의 결과를 씁니다.
- 낚은 물고기가 하나도 없는 페이지는 몇 페이지인지 구분할 수 없어서 "페이지를 알 수 없음"으로 표시되고, 목록에 영향을 주지 않습니다.
- 인식에 실패하면 "칸 위치 직접 고르기"로 첫 칸과 마지막 칸을 눌러 위치를 알려 줄 수 있습니다.

## 동작 방식

1. 스크린샷에서 칸 사이의 어두운 선이 일정한 간격으로 늘어선 곳을 찾아 10×10 격자 위치를 잡습니다. 격자 선이 옅어서 실패하면 "?" 칸 모양을 직접 찾아 격자를 맞춥니다.
2. 칸마다 그림을 작게 줄여, 그 자리에 와야 할 물고기 아이콘과 "?" 칸 그림 중 어느 쪽과 더 닮았는지 비교합니다.
3. 페이지마다 예상되는 아이콘 배치와 비교해 몇 페이지인지 판단합니다.

계산은 Web Worker에서 여러 장을 동시에 처리합니다.

## 파일 구성

| 파일 | 내용 |
|---|---|
| `index.html` | 화면과 내보내기 기능 |
| `core.js` | 격자 찾기와 칸 판독 로직 |
| `worker.js` | `core.js`를 백그라운드에서 돌리는 Web Worker |
| `fish.json` | 물고기 목록 (도감 순서, 한국어 이름, 트래커 포함 여부, 터주 여부) |
| `icons.png` | 물고기 아이콘 모음 |
| `unknown.png`, `blank.png` | "?" 칸과 빈 슬롯 견본 |
| `sample.png` | 처음 열었을 때 보여 주는 예시 스크린샷 |
| `example-crop.jpg`, `example-full.jpg` | 찍기 전 안내에 쓰는 예시 사진 |
